La importancia de las cosas

La importancia de las cosas no tiene nada que ver con la forma ni el contenido estas ni con el mundo material que nos rodea. Da igual si el universo es infinito, plano curvo o esférico. La importancia es el amor que se le tenga a algo, el valor que se le dé, el aprecio que se desprenda.
